# v2.4.2 — 窗口边框不再隐形

这一版只修一件事：**窗口最外圈那条 1px 边框**。但它是"用起来一直别扭、
又说不出哪里不对"的那种问题，值得单独发一版。

## 症状

浅色主题下，把窗口拖到另一个纯白应用（白底网页、Word、资源管理器）上面时，
**找不出窗口的边界**——看不出哪一块是自己的。截图里整个窗口像贴在白墙上，
连圆角的轮廓都要靠猜。

深色主题下同样的问题只是换了个方向：边框和标题栏同色，本来就是隐形的。

## 根因：我们自己把边框涂成了底色

标题栏自适应配色上线时，为了让边框"和标题栏融为一体"，代码把标题栏取到的
底色**原样**传给了边框：

```python
dwm.set_border_color(self, bg)      # 旧写法
```

界面本身是白的，取色结果就是 `#ffffff`，于是边框也成了 `#ffffff`。
日志里每次都是这一行：

```
标题栏上色：底色 #ffffff（取自界面 #ffffff）文字 #181a1f
```

## 先确认了一件事：边框和标题栏并不联动

动手之前先做了实测（新建窗口 + 屏幕逐像素取样，四边都取）：

| 操作 | 边框实际像素 |
|---|---|
| 什么都不设（系统默认） | `#C8C8C8` |
| **只设标题栏为纯白，完全不碰边框** | **`#C8C8C8`（纹丝不动）** |
| 标题栏纯白 + 边框也设纯白 | `#FFFFFF` ← 当前的问题 |
| 标题栏纯白 + 边框 `DWMWA_COLOR_DEFAULT` | `#C8C8C8`（交还系统） |

结论很清楚：Windows 的 `DWMWA_CAPTION_COLOR` 和 `DWMWA_BORDER_COLOR`
是两个独立属性（官方文档也没有联动说明），那圈白边是我们自己画上去的。
所以改边框**不可能碰到自适应取色的任何一环**——取色、降饱和、文字色对比度、
明暗判定、面板与托盘的主题联动，一行都没动。

## 修法：同族偏移，但方向跟着明暗走

不能简单"交还系统"，也不能简单"压暗一点"，两边都有硬伤：

- **交还系统**（`DWMWA_COLOR_DEFAULT`）：系统默认边框跟的是**系统**应用主题，
  不跟窗口自己的暗色模式 —— 实测深色标题栏下它照样画 `#C8C8C8`，
  对深底对比度 **9.35**，等于给深色窗口镶一圈发亮的轮廓，比看不见更难看。
  而且它是一抹中性灰，配彩色标题栏正是当初想躲的「异色线」。
- **一律压暗**：边框靠"与背后那个面"的色差被看见，不是靠"比标题栏深"。
  深色标题栏压暗 12% 得 `#202531`，与深色桌面（`#1B1B1D`）几乎同色，
  对比度只有 **1.20** —— 越修越看不见。

所以方向由亮度决定：**亮底压暗、暗底提亮**。强度实测比过 12% / 18% / 22%：

| 底色 / 背景 | 12% | 18% | **22%（采用）** | 系统默认 |
|---|---|---|---|---|
| `#FFFFFF` 对纯白应用 | 1.32 | 1.53 | **1.69 `#C7C7C7`** | 1.84 |
| `#242A38` 对深色应用 | 1.76 | 2.13 | **2.45 `#545964`** | 9.35 |

（表内是 1px 线对背景的 WCAG 对比度。）取 22%：亮色下基本等于系统原生灰线的
观感（1.84），深色下明显但不发光。强度是单个常数 `dwm.BORDER_TINT_RATIO`，
嫌重改一处就能回到 18%。

## 结果

| 主题 | 标题栏 | 边框 | 说明 |
|---|---|---|---|
| 浅色 | `#FFFFFF` | `#C7C7C7` | 白底上能看出边界，且仍是同一族的灰 |
| 深色 | `#242A38` | `#545964` | 比标题栏略亮一点，像自然的边缘高光 |

端到端实测（真实窗口 + 屏幕取样）：DWM 画出来的边框值与计算值逐位相同，
标题栏底色未受影响。

## 一个诚实的取舍

显式指定边框色之后，DWM 不再按窗口**激活状态**自动换边框色（微软文档写明
这项由应用自己负责）。本项目的标题栏底色本来就跟着界面走、不区分激活态，
所以保持一致；将来若要区分，在 `_apply_titlebar` 里加一个激活态分支即可。

## 顺带

`docs/desktop-shell-design.md` 补了「边框色：同族，但不能同色」一节，
把上面这些实测数据留在文档里，免得下次又有人为了"融为一体"把边框涂成底色。
自测里加了一条源码回归钉子：`_apply_titlebar` 中不允许再出现"边框=底色"的写法。
