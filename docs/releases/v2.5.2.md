# v2.5.2 — 界面细节与启动健壮性

这一版没有新功能，修的是两处看得见的观感，和三处「不该让启动失败」的坑。

## 界面

- **提示框**：鼠标悬停的说明从系统灰底黑框换成与界面同色的圆角卡片，行距和分段也正常了，暗色主题跟着走。
- **下拉列表**：去掉 Windows 自带的实色投影（右下那条硬边），换成细描边加一层很淡的底部阴影；箭头和滚动条按同一套配色重画。

## 启动

- 服务日志文件被占用时（上一个实例刚退出、或杀毒软件正在扫描），不再直接弹「DSH 启动失败」：先原地重试，仍不行就换一个备用日志文件继续启动。
- 网页引擎的缓存按 Qt 版本分开存放。同机用不同 Python 环境直跑源码时，两个版本不会再抢同一个缓存目录。

## 升级

直接更新即可，不需要手动清理。登录状态、设置和历史都留在原位置。
