# v2.5.3 — 修掉长会话崩溃

这一版只做一件事：修掉鲸坞跑久了会毫无征兆消失的问题。

## 崩溃修复

- **网页引擎换到含上游修复的版本**。旧版（QtWebEngine 6.11.2）里有个累积型缺陷：
  会话越长，内部的控件缓存被写坏的概率越高，最终直接在绘图线程上崩掉整个进程，
  日志里一个字都不留 —— 过去一个月里的 5 次消失，全都是它。
- 新版（6.11.3，Chromium 140.0.7339.264）的这段代码已被上游重写。
  这也是目前唯一带该修复的发行版本：更新的 6.12 那条线反倒不含它，
  6.11.3 是 6.11 线的最后一个版本。

## 升级

直接更新即可，不需要清理缓存或重新登录。登录状态、设置和历史都留在原位置。

> 说明：这次改动换来的是"缺陷代码已被替换"，是否还会出现其它崩溃需要在长会话里
> 继续观察；如果再次遇到，请把崩溃的模块名与偏移发给我们。
