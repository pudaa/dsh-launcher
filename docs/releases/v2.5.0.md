# v2.5.0 — 崩溃之后，不再留下一棵进程树

这一版有两件事：**崩溃/强杀后不再留下孤儿服务**（用户能感觉到的），
以及**把三个两千多行的文件拆开**（用户感觉不到，但决定了这个项目还能不能继续长）。

## 一、崩溃之后服务会被系统收走

### 问题

服务进程是"脱离式"启动的（`DETACHED_PROCESS`），为的是**关掉窗口之后后台任务还能继续跑**。

代价是：鲸坞进程一死，没人通知服务退场。

正常退出有兜底——点「退出」会执行 `taskkill /F /T`，杀整棵进程树
（实测能带走主进程和插件子进程）。但这两条路是空的：

- 进程崩溃（未捕获的异常、Qt 层面的 abort）
- 任务管理器里"结束任务"、或任何形式的强杀

留下的是一整棵 node 进程树，常驻 **600 MB 上下**。而且它不表现为故障：
下次启动会按端口认出它并接管，于是你看到的是"程序怎么越用越占内存"，
永远想不到是三天前那次崩溃留下的。

### 做法

Windows 的 Job Object 有个开关 `KILL_ON_JOB_CLOSE`：**持有 Job 句柄的进程全部消失时，
Job 里的进程一并终止**。

把它套在服务上，行为正好对上需求：

| 场景 | 结果 |
|---|---|
| 正常退出 | `taskkill /T` 先杀；Job 随后关闭，双保险 |
| **崩溃 / 被强杀** | **进程消逝 → 句柄由内核回收 → 服务树被系统杀掉** |
| 关掉窗口 | 鲸坞还在，句柄还在 → 服务照常继续跑（设计如此） |

实测：起一个父进程挂住子进程，然后 `taskkill /F`（**不带 `/T`**）杀掉父进程——
1.5 秒后子进程也被系统回收了。

唯一的例外是自更新重启：那条路故意不停服务，把端口交给新实例接管。
所以它在退出前会先摘掉这个限制，服务能活到新实例接手。

降级是安全的：Job 创建失败（权限、极老系统）只记一条日志，行为与改造前一致——
这类保障不该成为启动失败的理由。

### 顺带说清楚"关窗口"和"退出"

- **关掉窗口** = 最小化到托盘，服务继续跑，下次打开直接接管（这是特性）
- **「退出」** = 连服务一起停（这是"我要结束这一切"）

接管一个已经在跑的服务时，现在会弹一个托盘气泡告诉你一声，
而不是让你对着"刚打开就占着 600 MB"发愣。

## 二、Ctrl+C 现在等于正常退出

在终端里跑源码时，Ctrl+C 过去会在事件回调里抛 `KeyboardInterrupt`，
留下一条看不懂的报错，**而且绕过了退出流程**——服务不停、状态不清，
正好制造上面那种孤儿进程。

现在它走和托盘「退出」完全一样的路径：收线程、停服务、清状态。

## 三、代码结构

三个文件合计 9200 行，其中 `MainWindow` 一个类就有 2010 行 / 87 个方法。
改"更新"要先滚过"标题栏取色"，谁都不敢动。

拆完：

| 文件 | 之前 | 现在 |
|---|---|---|
| `dsh_gui_qt.py` | 3658 | **687**（只剩启动流程） |
| `dsh_panel.py` | 3108 | **并入 `dsh_ui/panel/`（6 个模块）** |
| `dsh_devtools.py` | 2445 | **并入 `dsh_ui/`（4 个模块）** |

`MainWindow` 按职责拆成七个分支（`dsh_ui/shell/`）：窗口骨架、视图、标题栏、
托盘、服务生命周期、更新、面板。状态留在主类，分支只放方法。

根目录现在**只有一个 `.py` 文件**：

```
dsh_gui_qt.py
dsh_host/   契约、适配、更新、供给、远程、生命周期、日志、作业对象
dsh_ui/     prelude / workers / dialogs / shell(7) / panel(6) / web(3) / devtools
tools/  docs/  assets/
```

这一节对使用者没有直接影响。写出来是因为它解释了一件事：**这次改动引入了几个
只在运行时才暴露的 bug**（`local_checks` 整个丢过、`_parse_probe_color` 没导出），
而它们全都来自"拆文件时漏了东西"。所以拆完补了一条固定动作——
用 AST 对比拆分前后的顶层定义，差集必须为空。

## 升级

覆盖安装即可，数据和登录态都在 `%LOCALAPPDATA%\DSH-Web`。

如果这次启动时看到"已接管一个正在运行的背景服务"的气泡，那是**上一版留下的**——
正好说明这一版要解决的问题。退出一次，之后就干净了。
